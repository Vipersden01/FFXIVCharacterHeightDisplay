# Height Display

See your size and others, drawn in the game's own type.

Height Display shows the height of each loaded party member and your current target beside the party list and target bar. Never guess how large someone is ever again! Enjoy the thrill of watching a big number get bigger? Or a small number smaller? Here you are-

## Install

Dalamud Settings -> Experimental -> Custom Plugin Repositories:

https://raw.githubusercontent.com/Vipersden01/FFXIVCharacterHeightDisplay/main/pluginmaster.json

Search for Height Display and install it. Open the config with `/displayheight`.

Height of current character can also be displayed in the world info bar!

## Settings

- Unit: centimeters, meters, or feet and inches. Decimals from 0 to 2.
- Auto unit conversion: convert measurement units to larger ones when you get large (or small) enough! Small meters become mm, μm, and nm. Small centimeters become μm, nm, and pm. Small feet become inches, then mils.
- Text size, from 0.75× to 2×.
- Party list side: always left or always right.
- Show party sizes and show target size.
- Flashy Height Text, glowing and animated numbers when changing size.
- World Bar Height Display
- Hide in combat, and hide in cutscenes.

## Notes

Only characters whose models are loaded can be measured.
